# Как менять «Bright — свой стиль»

Главный файл: **`public/map-styles/bright-custom.json`**.

Основа — копия `https://tiles.openfreemap.org/styles/bright` со 119 слоями. Теперь применена палитра Археокарты: фон `#F7F4ED`, территории `#E9E4DA`, вода `#A9CBDD`, водотоки `#85B4CE`, зелень `#CDDDBD`, здания `#D8CFC1`, контуры зданий `#B8AA97`, дороги `#FFFDF7`, обводки дорог `#C1B59F`. Подписи серые (`#494C45` / `#696C62`) со светлой обводкой `#FCFAF5`; русский язык имеет приоритет. Обычные POI скрыты, транспортные ориентиры сохранены. Здания плавно появляются с масштаба MapLibre 13 (Leaflet 14).

Контраст усилен: леса выделены цветом `#B8CCA8`, крупные дороги — мягким светло-жёлтым `#F5E5B9`, подписи воды — `#4F7A91`. Парки имеют непрозрачность 0,9, леса — 0,85.

Общий слой `park` отключён: его исходный фильтр закрашивал все полигоны источника `park`, включая охраняемые территории, которые не обязательно покрыты растительностью. Для зелёных зон оставлены `landcover-grass-park` (только `class: public_park`), `landcover-grass` и `landcover-wood`. Не включайте общую зелёную заливку `park` без уточнения категорий.

Обычный Bright остаётся отдельным вариантом для сравнения. Обновления оформления OpenFreeMap не перезаписывают локальный файл; географические данные по-прежнему поступают с OpenFreeMap.

В `metadata.archeomap:marker-palette` записана палитра будущих маркеров: чёрный `#252525`, синий `#2864AD`, красный `#B83D3D`, медный `#A66B3F`, обводка `#FFFCF5` толщиной 2 px. Это справочные значения для будущих значков: MapLibre не применяет их автоматически к существующим изображениям маркеров Leaflet.

## Как увидеть результат

1. Запустите сайт через `npm start`.
2. На странице `/map` выберите **Bright — свой стиль**.
3. Измените JSON и сохраните файл.
4. Переключитесь на другую подложку и обратно или обновите страницу. Уже открытая карта не перечитывает файл автоматически.
5. Проверьте общий вид города и крупный масштаб: оформление зависит от приближения.

При публикации выполните `npm run build` и опубликуйте новую сборку: каталог `public` попадёт в неё автоматически. Для пути подкаталога используется `PUBLIC_URL`.

## Где искать нужный объект

В файле найдите строку с нужным `"id"` (Ctrl+F). Редактируйте свойства внутри этого объекта массива `layers`.

| Что менять | ID слоёв в нашей копии | Основные свойства |
|---|---|---|
| Фоновый цвет | `background` | `paint.background-color` |
| Вода | `water`, `water-intermittent` | `paint.fill-color` |
| Реки, ручьи, каналы | `waterway-river`, `waterway-stream-canal`, `waterway-other` и их варианты | `paint.line-color`, `paint.line-width` |
| Парки, леса, трава | `park`, `landcover-wood`, `landcover-grass`, `landcover-grass-park` | `paint.fill-color`, `paint.fill-opacity` |
| Жилая застройка и промзоны | `landuse-residential`, `landuse-suburb`, `landuse-industrial` | `paint.fill-color` |
| Здания | `building`, `building-top` | `paint.fill-color`, `paint.fill-outline-color`, `paint.fill-opacity` |
| Дороги | `highway-minor`, `highway-secondary-tertiary`, `highway-primary`, `highway-trunk`, `highway-motorway` | `paint.line-color`, `paint.line-width` |
| Обводки дорог | соответствующие слои с окончанием `-casing` | `paint.line-color`, `paint.line-width` |
| Мосты и тоннели | слои с префиксами `bridge-`, `tunnel-` | Цвет и толщина линий |
| Названия улиц | `highway-name-path`, `highway-name-minor`, `highway-name-major` | `layout.text-size`, `layout.text-field`, `paint.text-color` |
| Названия населённых пунктов | `label_city`, `label_city_capital`, `label_town`, `label_village` | Те же параметры текста |
| Значки и подписи объектов | `poi_r1`, `poi_r7`, `poi_r20`, `poi_transit` | `layout.visibility`, `layout.icon-size`, `layout.text-size` |
| Административные границы | `boundary_2`, `boundary_3`, `boundary_disputed` | `paint.line-color`, `paint.line-width` |

У одного типа объектов бывает несколько слоёв. Например, для перекраски зданий проверьте **и `building`, и `building-top`**, а для дорог — также мосты, тоннели и обводки.

## Примеры изменений

Ниже — примеры дальнейшего редактирования стиля.

### Цвет воды

В слое `water` сейчас:

```json
"paint": {
  "fill-color": "#A9CBDD"
}
```

Можно заменить цвет, например, на `"#B9D3DE"`. Поддерживаются цвета HEX и CSS-форматы. `fill-opacity` от 0 до 1 регулирует прозрачность заливки. Для линий используйте `line-opacity`, для текста — `text-opacity`.

### Скрыть лишние значки

В существующем `layout` нужного слоя добавьте:

```json
"visibility": "none"
```

Вернуть слой: `"visibility": "visible"`. Для всех обычных POI проверьте `poi_r1`, `poi_r7`, `poi_r20`; транспортные объекты вынесены в `poi_transit`. Это скрывает весь соответствующий слой, включая подписи. Для удаления только определённых категорий нужно дополнить `filter`, предварительно проверив значения категорий в данных.

### Размер и цвет подписей

В `layout` слоя подписи:

```json
"text-size": 13
```

В его `paint`:

```json
"text-color": "#504B43",
"text-halo-color": "#FFFFFF",
"text-halo-width": 1
```

`text-halo-*` задаёт светлую обводку для читаемости. Вставляйте свойства в существующие объекты, не создавайте второй `layout` или `paint`. Не включайте повсеместно `text-allow-overlap`: названия начнут накладываться друг на друга.

### Русские названия

Замените `layout.text-field` в нужных слоях подписей на:

```json
["coalesce", ["get", "name:ru"], ["get", "name"], ["get", "name:latin"]]
```

Первым используется русское название, если оно есть в тайлах, иначе местное и затем латиница. Это не переводчик: отсутствующие в данных названия не появятся. Сейчас этот принцип уже применён к названиям в собственном стиле (с дополнительным запасным полем `name:nonlatin`). Номера дорог сохранены отдельно.

### Видимость при приближении

`minzoom` и `maxzoom` задаются рядом с `id` и `type`, вне `paint` и `layout`. Например, `"minzoom": 14` показывает слой начиная с масштаба 14; `maxzoom` — исключительная верхняя граница.

Наш адаптер Leaflet → MapLibre использует масштаб MapLibre на единицу меньше масштаба Leaflet. Поэтому `minzoom: 14` в стиле соответствует примерно Leaflet zoom 15.

Цвет, размер и толщина также могут плавно зависеть от масштаба. Пример значения `line-width`:

```json
["interpolate", ["linear"], ["zoom"], 10, 0.5, 16, 3]
```

На масштабе MapLibre 10 линия имеет толщину 0,5 пикселя, на 16 — 3 пикселя; между ними толщина плавно меняется. В исходном файле много таких выражений. Замена выражения числом делает параметр постоянным.

## Редактирование мышью в Maputnik

Откройте https://maputnik.github.io/editor/ и импортируйте **локальный JSON** через меню открытия/импорта стиля. Меняйте слои и цвета в редакторе, затем экспортируйте JSON и замените `public/map-styles/bright-custom.json`. Названия пунктов меню могут меняться между версиями редактора. Перед заменой полезно сохранить предыдущую версию через Git.

## Что не менять случайно

- `sources`, `glyphs`, `sprite` указывают на географические данные, шрифты и значки OpenFreeMap. Для перекраски их менять не требуется. Локально хранится оформление, а не вся карта для офлайн-работы.
- `source` и `source-layer` связывают слой с данными. Их изменение может скрыть объекты.
- Порядок элементов `layers` задаёт порядок рисования: поздние слои обычно оказываются поверх ранних.
- JSON не допускает комментариев и лишней запятой после последнего свойства.
- Сохраняйте указание источников. Атрибуция для карты настроена в `src/components/MapBasemap.jsx`.
- Значки археологических памятников и окна карточек находятся в `src/pages/MapPage.jsx` и `src/styles/MapPage.css`: они не входят в стиль подложки.

## Проверка файла

Из корня проекта:

```powershell
node -e "JSON.parse(require('fs').readFileSync('public/map-styles/bright-custom.json','utf8')); console.log('JSON OK')"
npm run build
```

Проверка JSON обнаруживает ошибки синтаксиса, но не гарантирует правильность свойств MapLibre. Сборщик копирует JSON из `public` как статический файл: после сборки обязательно проверьте карту в браузере и сообщения консоли.

Справочники: [слои и свойства MapLibre](https://maplibre.org/maplibre-style-spec/layers/), [выражения](https://maplibre.org/maplibre-style-spec/expressions/), [собственные стили OpenFreeMap](https://openfreemap.org/quick_start/).
