# Проверка рефакторинга CSS

Проверка выполнена 30 октября 2026 года в Microsoft Edge через Playwright, на работающем локальном сайте.

## Что сравнивалось

До изменений сохранены исходные стили, снимки страниц и данные API. Для окончательного сравнения браузер по очереди применял новые и исходные стили к одному и тому же содержимому страницы. Сравнивались снимки и все свойства, которые браузер вычислил для элементов. Это позволяет обнаружить изменения размеров, шрифтов, отступов, цветов и скрытых элементов.

Проверены 89 состояний основных страниц и карты, а также 20 дополнительных состояний с раскрытыми разделами, заполненной библиографией, поиском, наведением и фокусом. Во всех 109 состояниях рассчитанные стили совпали.

| Область | Проверки |
| --- | --- |
| Страницы | Приветствие, памятники, источники, проект, авторы, инструкция, отдельный памятник, заготовки новостей, словаря и статей |
| Карта | Пустая панель, выбранный памятник, фотографии, фильтры, выбор галочки, сворачивание панели |
| Навигация | Открытые верхнее и нижнее мобильные меню |
| Списки | Поиск памятников, разделы и поиск библиографии |
| Дополнительные состояния | Раскрытие всех разделов инструкции и проекта, раскрытие и закрытие групп фильтров, наведение на ссылки и кнопки |
| Фотографии | Миниатюры, прокрутка к галерее и открытая фотография |

Основные страницы проверены при ширине 390 и 1440 px. Карта и меню дополнительно проверены при 600, 601, 768, 1000, 1001, 1028, 1029, 1100 и 1101 px. Высота окна — 900 px.

Снимки совпали попиксельно в 107 из 109 состояний. В двух состояниях открытой галереи совпали все рассчитанные стили; различие отдельных каналов цвета фотографии составило не более 2 единиц из 255 при повторной отрисовке. Изменений геометрии и оформления не обнаружено.

## Условия и ограничения

- Использована копия реальных данных локального API. На сервер ничего не записывалось.
- Реальная библиография была пустой. Её заполненные состояния проверены на временных ответах, подставленных только в проверочном браузере.
- В сравнительных снимках плитки OpenStreetMap заменены одинаковой неподвижной подложкой, чтобы загрузка внешних картинок не влияла на результат. Маркеры, окно Leaflet и весь интерфейс карты оставались настоящими.
- Основной прогон использовал системную настройку уменьшения движения, чтобы сравнивать устойчивые состояния. Это не проверка промежуточных кадров анимации.
- Проверка не охватывает все браузеры, размеры окна и возможные данные API.

## Сборка и объём изменений

`npm run build` проходит. Сохранились существовавшие предупреждения о трёх неиспользуемых переменных в `Header.jsx` и зависимостях сборщика. `git diff --check` не выявил ошибок пробелов.

Количество объявлений в активных собственных стилях сократилось с 1578 до 1033, примерно на 35%. Сжатый CSS сборки, включая библиотеки, уменьшился примерно с 15,31 до 13,02 КБ. Функциональная логика компонентов не менялась: в JavaScript изменены только подключения CSS и относящиеся к ним пояснения.

## Как проверять дальнейшие изменения вручную

1. Откройте изменённую страницу на широком и узком экране.
2. Проверьте состояние до действия и после: открытое меню, выбранный фильтр, найденный памятник, открытая фотография.
3. Если изменён `@media`, проверьте ширину прямо перед границей и сразу после неё. Например, 1000 и 1001 px для карты.
4. Если изменены шапка или подвал, проверьте, что они не перекрывают содержимое и его прокрутку.
5. Выполните `npm run build`.
